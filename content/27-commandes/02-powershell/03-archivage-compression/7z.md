## Rôle

7-Zip en ligne de commande (à installer) : gère 7z, zip, gz, bz2, xz, tar.

## Options

| Option | Rôle |
| --- | --- |
| `a` | ajoute/crée une archive (add) |
| `x` | extrait en gardant l'arborescence |
| `e` | extrait à plat (tout au même endroit) |
| `l` | liste le contenu |
| `t` | teste l'intégrité |
| ⚠️ `-p ‹motdepasse›` | chiffre/déchiffre (mot de passe) |
| `-mx=‹9›` | niveau de compression (0 à 9) |
| `(-o‹dossier›)` | dossier de sortie, collé : -oC:\dest |

> [!WARNING]
> Options à manier avec précaution : `-p ‹motdepasse›`. Elles contournent une protection, détruisent des données ou agissent sans confirmation.

## Exemples

**Créer une archive**

```powershell
7z a backup.7z .\data
```

**Extraire**

```powershell
7z x backup.7z
```

**Archive chiffrée**

```powershell
7z a -p secret coffre.7z .\prive
```
