## Rôle

Outil de configuration de Windows Server, surtout en mode Core : réseau, domaine, nom, mises à jour. Depuis Server 2025, basé sur PowerShell.

## Options

| Option | Rôle |
| --- | --- |
| `(menu interactif)` | navigation par numéros |
| `(PowerShell)` | sconfig est désormais un script PowerShell extensible |

## Exemples

**Lancer le menu**

```powershell
sconfig
```

*Mots-clés : sconfig server core configuration menu réseau domaine nom serveur 2025*
