## Rôle

État du dépôt (court + branche).

## En détail

Montre l'état du projet : fichiers modifiés, ajoutés ou prêts à être valides. La commande qu'on tape le plus souvent pour se repérer.

## Options

| Option | Rôle |
| --- | --- |
| `-s` | court |
| `-b` | branche/suivi |

## Exemples

**Vue compacte**

```zsh
git status -sb
```
