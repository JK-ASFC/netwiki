## Rôle

Récupère et intègre (--rebase = linéaire).

## En détail

Récupère les modifications du dépôt distant et les intégré à votre copie locale. À faire pour rester à jour avec l'équipe.

## Options

| Option | Rôle |
| --- | --- |
| `--rebase` | rejoue au-dessus |
| `--ff-only` | refuse fusion |

## Exemples

**Pull propre**

```zsh
git pull --rebase
```
