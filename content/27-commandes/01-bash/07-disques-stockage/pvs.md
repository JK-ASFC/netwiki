## Rôle

Liste les Volumes Physiques (PV) connus de LVM.

## Options

| Option | Rôle |
| --- | --- |
| `-a` | tous les périphériques |
| `-v` | verbeux |

## Exemples

**Lister les PV**

```bash
pvs
```
