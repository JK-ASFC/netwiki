## Rôle

Partitionneur en interface texte (plus simple que fdisk).

## Options

| Option | Rôle |
| --- | --- |
| `-z` | démarre sur une table vide |

## Exemples

**Partitionner (menu)**

```bash
cfdisk /dev/sdb
```

*Mots-clés : partition cfdisk tui disque table partitionner interactif cfdisk*
