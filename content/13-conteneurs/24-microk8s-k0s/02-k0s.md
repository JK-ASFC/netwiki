**k0s** embarque tout Kubernetes dans **un seul binaire** sans prérequis (pas de Docker, pas de paquets) : idéal pour le bare metal, l'edge, les environnements isolés et les déploiements reproductibles avec **k0sctl**.

## Installation manuelle

```bash
curl -sSLf https://get.k0s.sh | sudo sh
sudo k0s install controller --single           # nœud unique (controller + worker) ; « controller » seul en cluster
sudo k0s start && sudo k0s status
sudo k0s kubectl get nodes
sudo k0s token create --role=worker > jeton-worker          # sur un controller
sudo k0s install worker --token-file jeton-worker && sudo k0s start   # sur le worker
```

## Déploiement avec k0sctl

```yaml
# k0sctl.yaml
apiVersion: k0sctl.k0sproject.io/v1beta1
kind: Cluster
metadata: { name: prod }
spec:
  hosts:
    - { role: controller, ssh: { address: 10.0.20.41, user: root, keyPath: ~/.ssh/id_ed25519 } }
    - { role: controller, ssh: { address: 10.0.20.42, user: root, keyPath: ~/.ssh/id_ed25519 } }
    - { role: controller, ssh: { address: 10.0.20.43, user: root, keyPath: ~/.ssh/id_ed25519 } }
    - { role: worker, ssh: { address: 10.0.20.51, user: root, keyPath: ~/.ssh/id_ed25519 } }
  k0s:
    config:
      spec:
        network: { provider: calico }
```

```bash
k0sctl apply --config k0sctl.yaml      # installe ou met à jour tout le cluster
k0sctl kubeconfig --config k0sctl.yaml > ~/.kube/config
k0sctl backup --config k0sctl.yaml     # sauvegarde des controllers
```

k0sctl tourne sur Linux, macOS et Windows (`winget install k0sproject.k0sctl` ou binaire). Commandes : [[90-aide-memoire|aide-mémoire]].
