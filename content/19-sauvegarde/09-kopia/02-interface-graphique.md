**KopiaUI** (Windows, macOS, Linux) lance un serveur Kopia local et l'affiche dans une fenêtre ; la même interface est servie par `kopia server` dans un navigateur.

| Onglet | Contenu |
| --- | --- |
| **Snapshots** | Dossiers sauvegardés, *New Snapshot*, historique, parcourir, **Restore**, **Mount** |
| **Policies** | Planification, rétention, fichiers exclus, compression, actions avant/après |
| Tasks | Tâches en cours et terminées (instantanés, maintenance) |
| Repository | Type de stockage, état, déconnexion |
| Preferences | Thème, langue, lancement au démarrage |
