## LibreNMS

| Écran | Contenu |
| --- | --- |
| **Tableau de bord** | Widgets : équipements hors service, alertes, top trafic, carte |
| **Devices** | Liste par type, état, emplacement |
| Page d'un équipement | Vue d'ensemble, **Ports** (trafic, erreurs), **Health** (CPU, mémoire, températures), **Routing** (BGP, OSPF), **Neighbours**, Inventory, **Config** (Oxidized), Logs |
| **Maps** | Carte réseau issue de LLDP/CDP |
| **Alerts** | Alertes actives, règles, transports, modèles |
