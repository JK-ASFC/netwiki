| Écran | Usage |
| --- | --- |
| **Alerts** | Alertes regroupées par règle ; *Acknowledge*, *Escalate* vers un cas |
| **Dashboards** | Vues prêtes : DNS, HTTP, SSL, fichiers, connexions |
| **Hunt** | Requêtes libres, pivots d'une valeur à l'autre |
| **Cases** | Incidents : observables, commentaires, pièces, chronologie |
| **Detections** | Règles NIDS (Suricata), HIDS (Sigma), YARA |
| **PCAP** | Paquets d'une connexion, téléchargement |
| **Grid** | État des nœuds et services |
| Kibana, Fleet | Analyse avancée, gestion des agents |
