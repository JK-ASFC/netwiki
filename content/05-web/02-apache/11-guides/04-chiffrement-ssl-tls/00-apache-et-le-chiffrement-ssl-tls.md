Le module [[12-modules/mod_ssl|mod_ssl]] du serveur HTTP Apache fournit une interface avec la bibliothèque [OpenSSL](http://www.openssl.org/), qui permet d'effectuer un chiffrement fort en s'appuyant sur les protocoles "Couche Points d'accès Sécurisés" (Secure Sockets Layer - SSL) et "Sécurité de la Couche Transport" (Transport Layer Security - TLS).
