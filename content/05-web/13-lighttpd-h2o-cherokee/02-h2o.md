**H2O** (MIT) est un serveur HTTP très rapide, pionnier de **HTTP/2** et de **HTTP/3/QUIC** (bibliothèque quicly). Il fait serveur de fichiers, reverse proxy et peut exécuter du **mruby**. Il est moins répandu que [[03-nginx/01-presentation|NGINX]] ou [[04-caddy/01-presentation-installation|Caddy]] (lequel offre aussi HTTP/3 avec certificats automatiques), mais reste une référence pour la performance HTTP/2-3.

## Installation

```bash
sudo apt install h2o                    # Debian/Ubuntu (version parfois ancienne)
sudo dnf install h2o                    # Fedora
sudo pkg install h2o                    # FreeBSD
brew install h2o                        # macOS
```

Version récente : compilation depuis `github.com/h2o/h2o` (`cmake -B build && cmake --build build && sudo cmake --install build`). Windows : non pris en charge nativement.

## `/etc/h2o/h2o.conf`

```yaml
user: www-data
access-log: /var/log/h2o/access.log
error-log: /var/log/h2o/error.log
listen: &ssl_listen
  port: 443
  ssl:
    certificate-file: /etc/letsencrypt/live/www.corp.exemple.fr/fullchain.pem
    key-file: /etc/letsencrypt/live/www.corp.exemple.fr/privkey.pem
    minimum-version: TLSv1.2
# HTTP/3 (QUIC) sur le même port en UDP
listen:
  <<: *ssl_listen
  type: quic
header.set: "Alt-Svc: h3=\":443\""
hosts:
  "www.corp.exemple.fr:443":
    paths:
      "/":
        file.dir: /var/www/html
        compress: ON
      "/api":
        proxy.reverse.url: http://10.0.20.10:8080/
        proxy.preserve-host: ON
  "www.corp.exemple.fr:80":
    listen:
      port: 80
    paths:
      "/":
        redirect: https://www.corp.exemple.fr/
```

(H2O accepte plusieurs clés `listen` au même niveau, contrairement au YAML strict.)

```bash
sudo h2o -t -c /etc/h2o/h2o.conf      # tester
sudo systemctl restart h2o
curl -sI --http3 https://www.corp.exemple.fr/   # curl compilé avec HTTP/3
```

Ouvrir **UDP 443** sur le pare-feu pour HTTP/3. Commandes : [[90-aide-memoire|aide-mémoire]].
