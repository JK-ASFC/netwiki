| Menu | Contenu |
| --- | --- |
| **Hosts** | Tous les hôtes, création (PXE, VM), *Register Host*, *Schedule Remote Job*, errata applicables |
| **Configure** | Host Groups, rôles Ansible, classes Puppet |
| **Infrastructure** | Smart Proxies, Subnets, Domains, Compute Resources (VMware, Proxmox, libvirt) |
| **Content** | Products, Repositories, **Content Views**, Lifecycle Environments, Errata, Activation Keys, Sync Status |
| **Monitor** | Tâches, rapports de configuration, conformité (OpenSCAP) |
