title: Interface graphique
description: Interface web de Rundeck — liste des projets, tableau de bord du projet, Jobs (lancement avec options, planification), Activity (historique et journaux d'exécution), Nodes (filtres, commandes ad hoc), Key Storage, configuration du projet et administration système (ACL, utilisateurs, greffons), avec emplacements de captures d'écran.
tags: [rundeck, interface graphique, captures]
icon: monitor
---

| Écran | Contenu |
| --- | --- |
| **Jobs** | Arborescence des tâches par groupe, bouton *Run Job Now* avec formulaire d'options |
| **Activity** | Historique, journal détaillé par nœud, relance |
| **Nodes** | Filtres, attributs, **Commands** (commande ad hoc sur une sélection) |
| Project Settings | Sources de nœuds, exécuteurs (SSH, WinRM, Ansible), Key Storage |
| System Menu | ACL, greffons, utilisateurs et sessions |
