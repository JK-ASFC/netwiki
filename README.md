# Contenu NetWiki

Branche générée automatiquement chaque semaine par le workflow « Publication hebdomadaire du contenu ».
Elle ne contient que le dernier paquet d'articles signé par JK-ASFC (`netwiki-contenu.netwiki`) et son index (`contenu.json`).
Ne pas modifier à la main : les articles se modifient dans le dossier `content/` de la branche `main`.
